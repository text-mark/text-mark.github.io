<text-mark>

A native Web Component for marking text ranges with annotations and custom styling

Highlight text ranges directly in the editor with simple mouse selection

🏷️ Annotations

Add names and detailed annotations to each marked range

🎨 Custom Colors

Choose custom colors for each text range with an integrated color picker

See live updates as you modify range properties

Demo

Usage

Basic Implementation

Simply add the component to your HTML:

<text-mark></text-mark>

Include the Script

<script src="text-mark.js" type="module"></script>

Features

  • Text Selection: Click and drag in the left textarea to select and highlight text ranges
  • Range Management: Each selected range appears in the right column as an editable item
  • Properties:
    • START - Starting position in the text
    • END - Ending position in the text
    • NAME - Label for the range
    • ANNOTATION - Detailed notes about the range
    • COLOR - Highlight color for the range
  • Live Updates: Changing any property in the right column immediately updates the textarea highlighting and styling

How It Works

Two-Column Layout

The component displays a two-column interface:

  • Left Column: A textarea where you can enter and edit text, with visual highlighting of marked ranges
  • Right Column: A list of all marked ranges with editable properties and controls

Creating Ranges

  1. Select text in the textarea by clicking and dragging
  2. The selected range automatically appears in the right column
  3. Edit the range properties as needed
  4. Changes are reflected immediately in the textarea

Editing Ranges

For each range in the right column, you can:

  • Adjust the START and END positions with numeric input fields
  • Add or edit the range NAME
  • Add detailed ANNOTATION text
  • Choose a highlight COLOR with the integrated color picker
  • Delete ranges using the delete button

API Reference

Properties

Property Type Description
text String The text content in the editor
ranges Array Array of text range objects
defaultColor String Default highlight color (hex color code)

Range Object Structure

{
  start: 0,                    // Start position in text
  end: 10,                     // End position in text
  name: "Entity",              // Range label
  annotation: "Important text",// Detailed notes
  color: "#FFFF00"             // Highlight color
}
